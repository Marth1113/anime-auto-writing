# アニメ原作・小説 自動執筆プロジェクト (anime-auto-writing)

本リポジトリは、Google Antigravity（企画・設定構築）と Google Jules（自律執筆エージェント）を連携して制作する小説・アニメ原作プロジェクトです。

## ディレクトリ構成
- `AGENTS.md`: Julesへの執筆ルール・文体指示
- `notes/`: 設定資料
  - `world.md`: 世界観・用語集
  - `characters.md`: キャラクター設定
  - `plot.md`: 全体あらすじ＆章別プロット
- `chapters/`: 原稿本文格納ディレクトリ
