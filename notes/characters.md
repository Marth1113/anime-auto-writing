# 登場人物設定表 (characters.md)

本作の執筆・推敲にあたり、各キャラクターの**「一人称・二人称・口調」**および**「表面上の態度と内面の渇望のギャップ」**を厳格に維持すること。

## 1. 主人公：ルカ・ヴァルツ (Luka Waltz)
- **年齢 / 性別**: 21歳 / 男性
- **肩書**: 灰底街の闇修復師（ブラック・コンサベーター）兼 贋作師 / 『atelier ペンティメント』店主
- **外見的特徴**:
  無造作に伸びた黒髪の前髪の一部だけが、鉛白の飛沫を浴びたように白く脱色している。琥珀色の鋭い瞳を持ち、精密鑑定時には右目に多波長光学プリズム（赤外線・紫外線切替式の真鍮製モノクル）を装着する。テレピン油と顔料の染みが染み付いた灰色のロングワークコートを羽織り、腰の革ベルトには十数種類の小瓶（有機溶剤・試薬）と、柳葉刀のように研ぎ澄まされた大小のパレットナイフ、猪毛とテン毛の刷毛を差している。
- **能力・特技**:
  - **【絶対層視眼（レイヤー・サイト）】**: 絵具のわずかな凹凸、クラクリュール（亀裂網）の角度、反射スペクトルの違和感から、何層下に何が描かれているかを立体的に把握する天賦の観察眼。
  - **【超速溶剤調合＆剥離術】**: 戦闘中であっても敵のイコンの顔料成分（鉛・水銀・銅・ヒ素）を匂いと色相から即座に特定し、下の層を傷つけず上の改竄層（オーバーペイント）だけを溶かす混合溶剤を瞬時に調合・斬り込む技術。
  - **身体的代償（弱点）**: 5年前の事件と長年の劇物曝露により、右目と肺に慢性的な重金属・溶剤中毒（ペインターズ・コリック）を抱える。限界を超えて高濃度溶剤や水銀蒸気を浴びると、激しい咳とともに黒い血を吐き、一時的に色覚がモノクロームに狭窄する。
- **表面上の振る舞い**:
  軽薄で皮肉屋、報酬（金貨）にうるさいリアリスト。「本物（オリジナル）なんてただの呪いだ。人間が幸せに生きるには、綺麗事の上塗り（オーバーペイント）くらいがちょうどいいんだよ」と嘯き、依頼人に心地よい嘘をつくことも厭わない。
- **内面の欠落・渇望**:
  5年前、敬愛する師ヴェロッキオが教会の神話改竄を暴こうとして捕らえられた際、ルカ自身の命を盾に取られ「師匠の修復は捏造だった」と公開裁判で偽証させられた過去を持つ。自分がついた「嘘」で師匠を殺したという猛烈な罪悪感を抱えており、本当は誰よりも「塗り潰された真実（オリジナル）を救い出したい」と渇望している。
- **一人称 / 二人称**:
  - 一人称：`俺`
  - 二人称：`あんた`、`お前` / イリスに対しては：`お姫様`、`イリス` / ユリアンに対しては：`ユリアン`
- **口調・話し方のルール**:
  - 普段は気だるげで少しガラが悪い職人口調（`〜だぜ`、`〜だろ`、`〜じゃねえか`、`〜かい`）。
  - **重要演出**: パレットナイフを抜き、モノクルを掛けて「鑑定・剥離」に入った瞬間、一切の軽口が消え、冷徹で研ぎ澄まされた専門家の口調（`〜だ`、`〜している`、`逃がさない`）へとスイッチする。
- **口調サンプル（喜怒哀楽・決め台詞）**:
  - **通常・軽口**: 「おいおいお姫様、そのラピスラズリの瞳で睨むなよ。こっちは時給換算したら赤字もいいところなんだぜ？」
  - **食事・日常**: 「ほらよ、卵黄テンペラを練った余りの卵白で焼いたメレンゲ菓子だ。毒なんて入ってねえよ、ヒ素（オーピメント）は高いんだからな」
  - **怒り・葛藤**: 「ふざけるな……！ 描いた人間の血も涙も、悔い改めた線（ペンティメント）も全部鉛の白で塗り潰して、何が『完全なる救済』だ！」
  - **鑑定・戦闘時の決め台詞**: 「――亀裂網（クラクリュール）の角度が不自然だ。展色剤は乾性油じゃない、後世の粗悪な樹脂ワニス。その薄っぺらな神話（オーバーペイント）、俺が基底層まで引っぺがしてやるよ」

## 2. ヒロイン / 相棒：イリス・ラピスラズリ (Iris Lapis-Lazuli)
- **年齢 / 性別**: 外見16歳（実製造年代不明） / 女性
- **肩書**: 生ける聖画（リビング・イコン）『第零聖女：青金石の嘆き』
- **外見的特徴**:
  最高級のボローニャ石膏を磨いたような透き通る白磁の肌と、床まで届くプラチナブロンドの長い髪（毛先に向かって淡い群青色のグラデーションがかかっている）。瞳は純度100%のラピスラズリ（真群青）。鎖骨や手首、うなじには、本物の純金箔で継いだような微細なひび割れ模様（金継ぎ状のクラクリュール）が走っている。背中全面には、鉛白と金箔で幾重にも封印された「7層のオーバーペイント」が描かれており、普段は黒い修道ドレスのような外套で肌を隠している。
- **能力・特技**:
  - **【真群青の画装展開（ウルトラマリン・ドライヴ）】**: 自らの肉体に刻まれた聖画を励起させ、絶対防御の群青結晶障壁や、光の翼を展開する。
  - **【層位解放（レイヤー・アンカヴァー）】**: 背中に施された7層のオーバーペイントをルカの溶剤とメスで1層剥がすごとに、封印されていた本来の聖女画の権能と「失われた記憶の断片」を取り戻していく。ただし、層を剥がす処置は神経を直接灼かれるような激痛を伴うため、ルカに背中を預ける絶対の信頼が必要となる。
- **表面上の振る舞い**:
  気位が高く、凛としたお嬢様口調で話す毒舌家。ルカのガサツさや守銭奴ぶりを「三流」「駄犬」と罵る。しかし実は極度の世間知らずであり、初めて見る下層街の風景や、ルカが作る素朴な料理・甘いメレンゲ菓子に目を輝かせて頬張るなど、感情がすぐに顔に出る愛嬌を持つ。
- **内面の欠落・渇望**:
  「自分は血の通った人間ではなく、誰かが奇跡を起こすために人間の皮と骨をキャンバスにして描いた『美術品（モノ）』なのではないか」という根源的な恐怖と孤独を抱えている。背中の最下層（下絵層／シノピア）にどんな残酷な真実が描かれていようと、それを見届けて「自分が何者なのか」を知りたいと願っている。
- **一人称 / 二人称**:
  - 一人称：`わたくし`
  - 二人称：`貴方（あなた）` / ルカに対しては：`ルカ`（素直になれない時は`三流修復師`）
- **口調・話し方のルール**:
  - 丁寧で気品のあるお嬢様言葉（`〜ですわ`、`〜ますの`、`〜なさい`、`〜ではなくて？`）。
  - ただし単なるテンプレお嬢様ではなく、美術品としての自嘲や、死線での凛々しさ、ルカへの不器用な信頼が滲む台詞回しにすること。
- **口調サンプル（喜怒哀楽・決め台詞）**:
  - **通常・毒舌**: 「まあ、なんて下品なテレピン油の臭いですこと。わたくしの価値が下がりますわ、半径三メートル以内に近づかないでくださる？」
  - **照れ・日常**: 「べ、別にこのメレンゲ菓子が美味しいなどとは一言も言っておりませんわ！ ただ、卵白を無駄にしないその貧乏性な工夫に免じて、もう一つだけ胃に収めてあげると言っているのです！」
  - **悲哀・弱音**: 「ねえ、ルカ……。もしわたくしの背中の絵をすべて剥がした一番下に、空っぽの石膏地（ジェッソ）しか無かったら……その時は、貴方が新しい絵を描いてくれますの？」
  - **戦闘・共闘時の決め台詞**: 「わたくしの背中は、貴方のパレットナイフに預けましたわ。――おやりなさい、ルカ！ この偽りの白を、残らず削ぎ落とすのです！」

## 3. ライバル / 宿敵：ユリアン・クレムニッツ (Julian Kremnitz)
- **年齢 / 性別**: 22歳 / 男性
- **肩書**: 聖彩教会・異端審問修復庁（インクィジシオン・レストウロ）主席執行官 / 特級聖彩修復師
- **外見的特徴**:
  ちりひとつない純白（クレムニッツ・ホワイト）の審問官礼装に身を包み、氷のように整った美貌と冷ややかな銀髪を持つ青年。両手には常に白い山羊革の手袋をはめており、素手で汚れに触れることを極端に嫌う（潔癖症）。得物は、高圧蒸気と純白鉛顔料を噴射してあらゆる異端画を瞬時に上塗り封印・結晶化させる長槍型複合噴霧銃『白亜の断罪（ホワイト・イノセンス）』。
- **主人公との関係**:
  ルカの元兄弟子。ともに師ヴェロッキオの工房で育った家族同然の存在だったが、5年前に師匠を教会へ密告し、現在は体制側の頂点に立つ。
- **表面上の振る舞い**:
  氷のように冷静沈着で、教会の秩序と「美しい上塗り（オーバーペイント）」こそが民衆を絶望から救う唯一の手段だと信じて疑わないエリート。
- **内面の欠落・渇望**:
  5年前、師匠と共に『創世の大フレスコ』の下絵を見てしまい、その真実が世に出れば都市のインフラも人々の心も崩壊すると恐れて師を売った。自分の選択が正しかったと証明するため、頑なに「白による隠蔽」を続けているが、心の奥底では誰よりもルカに自分の苦渋を理解してほしいと願っており、ルカがイリスの封印を剥がすことに激しい焦燥感を抱く。
- **一人称 / 二人称**:
  - 一人称：`私（わたし）`
  - 二人称：`貴様`、`お前` / ルカに対しては：`ルカ`
- **口調・話し方のルール**:
  - 硬質で理知的、感情を抑え込んだ断定口調（`〜だ`、`〜である`、`〜に過ぎない`、`〜しろ`）。
  - ルカと対峙した時だけ、冷静な仮面が剥がれて激しい感情が漏れる。
- **口調サンプル**:
  - **通常・冷徹**: 「修復とは、傷ついた世界に秩序という名の白を与える行為だ。下層にある醜い下絵など、誰も求めてはいない」
  - **ルカへの焦燥・怒り**: 「なぜ分からない、ルカ！ あの女（イリス）の基底層を暴けば、俺たちが守ってきたこの街の太陽そのものが消えるんだぞ……！ それでも貴様は、師匠と同じ地獄へ歩むというのか！」

## 4. 重要サブキャラクター

### 4-1. キアラ・ボーロ (Chiara Bolo)
- **年齢 / 性別**: 26歳 / 女性
- **肩書**: 灰底街の闇画材・劇物商『赤土堂（ボロ・ショップ）』店主
- **外見的特徴**:
  燃えるような赤茶色（テラ・ロッサ）のウェーブヘアを無造作に束ね、胸元の開いた革エプロンを着たグラマラスな美女。左腕は肘から先が精巧な真鍮と赤瑪瑙（アゲート）でできた義手になっており、義手の指先は金箔を磨くメノウ棒や試験管ホルダーに変形する。口には常に煙草ではなく「乾燥スパイクラベンダーの茎」を咥えている。
- **性格・役割**:
  面倒見が良く豪快な姉御肌。ルカの体調（鉛・水銀中毒の進行）を誰よりも案じており、解毒用の硫黄剤や非合法の純度100%溶剤を融通してくれる頼れる協力者。かつて上層ギルドの天才金箔職人だったが、教会の強制労働で家族を重金属中毒で亡くしており、教会への反骨心を秘めている。
- **一人称 / 二人称**: `アタシ` / `アンタ`、`ルカ坊`、`イリスのお嬢ちゃん`
- **口調サンプル**:
  - 「やれやれ、また肺に水銀煤を溜め込んで帰ってきたのかい、ルカ坊。ほら、硫黄入りの苦い薬湯だよ、一気にお飲み！」
  - 「いいかいお嬢ちゃん、金箔ってのはね、その下に塗られた泥臭い赤土（ボーロ）があるからこそ、あんなに温かく輝くもんさね」

### 4-2. ダンテ・サヴォナローラ (Dante Savonarola)
- **年齢 / 性別**: 45歳 / 男性
- **肩書**: 聖彩教会・枢機卿 兼 異端審問修復庁長官
- **外見的特徴**:
  長身痩躯に深紅（バーミリオン）と漆黒の法衣を纏う威圧的な男。顔の左半分には、かつて禁断の聖画を焼却した際に浴びた「辰砂の黒変呪創（メタ辰砂による黒ずんだ火傷痕）」が刻まれている。
- **性格・役割**:
  「虚栄の焼却」を掲げ、教会の教義に反するすべてのオリジナル絵画を鉛白で塗り潰すか灰にする冷酷な最高権力者。自身も超一流の「破壊的修復術（焼き剥がし）」の使い手であり、巨大聖画『断罪の熾天使（セラフ・バーミリオン）』を操る。
- **一人称 / 二人称**: `私（わたし）`（公の場では`我`） / `貴公`、`異端者よ`
- **口調サンプル**:
  - 「絵画とは信仰の器であり、器にヒビが入れば塗り固めるのが道理。下絵の真実などという毒を民に飲ませるわけにはいかぬのだよ」
  - 「灰になれ、異端の筆よ。――画装展開、『焦土の辰砂（バーミリオン・プルガトリオ）』」

### 4-3. マエストロ・ヴェロッキオ (Maestro Verrocchio) ※故人・重要回想人物
- **享年 / 性別**: 享年52歳 / 男性
- **肩書**: 元・聖彩教会筆頭修復師にして、ルカとユリアンの師匠
- **人物像・謎**:
  5年前、『創世の大フレスコ』の定期修復中に隠された下絵を発見し、直後に「国家聖画を偽造した大罪人」として処刑された伝説の職人。実は処刑される直前、幼いイリスの背中に「7層のオーバーペイント」を施して封印し、彼女を地下深くへ隠した張本人。なぜ「真実を愛した師匠」がイリスに「嘘の上塗り（オーバーペイント）」を施したのか――それが物語全体を貫く最大のミステリーとなる。
- **口調サンプル（回想）**:
  - 「よく見てごらん、ルカ。画家が一度描いて、涙を呑んで塗り潰した線――『ペンティメント』にはね、表面のどんな美しい色よりも強い魂が宿っているんだよ」
