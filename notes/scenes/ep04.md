# 第4話 シーン詳細設計書 (ep04.md)

- **サブタイトル**: 第4話『真夜中の贋作オークションと紫外線（ブラックライト）の罠』
- **視点**: 三人称一元視点（ルカ・ヴァルツ視点）
- **目標文字数**: 4,800〜6,000文字

## Scene 1：解けない第3層と「師匠の遺品」の情報
- **場所・時間帯**: キアラの闇画材商『赤土堂』の奥座敷 / 昼
- **登場キャラ**: ルカ、イリス、キアラ
- **起こる出来事**:
  1. **冒頭フック**: 第3話の激戦でヒ素と鉛の微粒子を吸い込んだルカに、キアラが特製の苦い硫黄解毒茶を無理やり飲ませ、イリスが「まあ、情けない顔ですこと」と毒づきつつも心配そうに背中をさすっているシーン。
  2. ルカはイリスの第3層の分析結果を語る。第3層は「緑青（塩基性炭酸銅）」と「乾性クルミ油」が長年の反応でガラスのように硬化した**『銅石鹸（カッパー・ソープ）化グレーズ層』**であり、師匠が刻んだ警告通り、力任せに溶かせばイリスの心臓の石膏地まで割れてしまう。
  3. 安全に剥がすには、師匠ヴェロッキオが生前に使っていた『共鳴剥離メス』と『門外不出の溶剤処方録』が必要不可欠。キアラは「ちょうど今夜、中層区の貴族サロンで開かれる地下オークションに、教会から横流しされたヴェロッキオの遺品と未公開遺作が出品されるよ」と招待状を取り出す。
- **五感・映像演出のポイント**:
  - 『赤土堂』の棚に並ぶ色とりどりの鉱石（孔雀石、辰砂原石、ラピスラズリ原石）とスパイクラベンダーの香り。

## Scene 2：貴族と少女人形――地下オークション潜入
- **場所・時間帯**: 中層「彩光市民区」・バル디貴族館の地下仮面オークション会場 / 夜
- **登場キャラ**: ルカ、イリス、腐敗した美術ギルド長バルディ（主催者）
- **起こる出来事**:
  1. 審問庁の目を欺くため、ルカは黒髪を後ろに撫でつけた「新興貴族の若き蒐集家」に、イリスは一切言葉を発しない「最高級の少女人形（オートマタ）」に変装して会場へ潜入する。
  2. 普段のボロ布とは違う豪華な群青のドレスに身を包んだイリスの美しさに会場がざわめく。人形になりきらなければならないのに、会場のビュッフェの焼き菓子に視線が釘付けになり、ルカに小声でツッコまれるコミカルなやり取り。
  3. ステージに主催者である美術ギルド長バルディが登場し、目玉商品として「処刑された大罪人ヴェロッキオの遺品（メスと処方録）」および「ヴェロッキオ幻の最高傑作イコン」3枚を同時に提示する。
- **五感・映像演出のポイント**:
  - シャンデリアの黄金の光、貴族たちの仮面、イリスのドレスの絹の衣擦れの音。

## Scene 3：公開鑑定バトル――クラクリュール（経年亀裂）の嘘を暴け
- **場所・時間帯**: 地下オークション会場のメインステージ / 夜
- **登場キャラ**: ルカ、イリス、バルディギルド長、会場の貴族たち
- **起こる出来事**:
  1. バルディは法外な競り値を吊り上げるため、「この3枚のヴェロッキオ画のうち、真作を見抜けた者には遺品のメスと処方録を無償で譲ろう。ただし外せば全財産と命を頂く」と傲慢な余興を持ちかける。
  2. ルカが名乗りを上げてステージに登壇する。3枚の絵画はいずれも精巧を極め、通常の鑑定師では見分けがつかない。
  3. **知的ミステリー・ハイライト**: ルカはモノクルを**紫外線（UV）プリズム**に切り替え、会場の照明を落とさせる。
     - 1枚目の絵：UV照射によって表面のワニスが「緑色の不自然な蛍光」を放つ。「天然の古い樹脂ワニスはこうは光らない。しかも亀裂網（クラクリュール）にインクをすり込んで古色を偽装した『描き亀裂』だ」。
     - 2枚目の絵：オーブンで急激に乾燥させて作った「焼き亀裂」。ルカは「本物の経年亀裂は木目（支持体）の繊維方向に対して垂直に走るが、これは熱収縮で全方向に丸く割れている」と科学的に論破。
     - そして3枚目の絵：ルカは「3枚目も贋作だ！」と宣言し、会場が騒然となる。バルディが「馬鹿な、3枚目は本物のヴェロッキオの板絵だ！」と激昂すると、ルカはパレットナイフで3枚目の表面（バルディが価値を高めるために上から加筆した豪華な金彩オーバーペイント）を一瞬で削ぎ落とし、その下に隠されていた**「バルディ自身の不正取引の帳簿兼・師匠の処方録のインデックス画」**を暴き出す！
- **五感・映像演出のポイント**:
  - 暗闇の中で紫外線（ブラックライト）に照らされて浮かび上がる蛍光色と、ルカのロジカルで鮮やかな解説演出。

## Scene 4：奪還された処方録と地下廃鉱山の座標（クリフハンガー）
- **場所・時間帯**: オークション会場からの脱出路（運河のゴンドラの上） / 深夜
- **登場キャラ**: ルカ、イリス
- **起こる出来事**:
  1. 顔面蒼白になったバルディが用心棒の彩獣を差し向けるが、人形のふりをやめたイリスが「ずっと黙っているのは肩が凝りましたわ！」と華麗な群青の蹴りと障壁で一蹴。二人は『共鳴剥離メス』と『処方録の板絵』を奪還してゴンドラへと飛び降り、夜の運河へ颯爽と逃走する。
  2. ゴンドラの上で、イリスが「ルカ、先ほどステージの上で師匠の絵を語っていた時の貴方の目……少しだけ、悪くありませんでしたわ」と不器用に褒める。
  3. **終盤の引き（クリフハンガー）**: ルカが奪還した処方録の板絵に赤外線プリズムを当てると、イリスの第3層・第4層を剥がすための特殊触媒の採取場所として、都市の最深部にある立入禁止区域――**『旧ボローニャ石膏廃鉱山・生体基底実験場（カタコンベ）』**の地図が浮かび上がる。「生体基底実験場……？ まさか、お前が作られた場所なのか……？」という緊迫の引きで幕を閉じる。
