# 第1話 シーン詳細設計書 (ep01.md)

- **サブタイトル**: 第1話『鉛白（クレムニッツ・ホワイト）の棺と群青の少女』
- **視点**: 三人称一元視点（ルカ・ヴァルツ視点）
- **目標文字数**: 4,800〜6,000文字（各シーン1,200〜1,500文字目安）

## Scene 1：灰底街の闇修復師と「優しい嘘」
- **場所・時間帯**: 最下層「灰底街」の水路沿い・闇修復工房『atelier ペンティメント』 / 深夜
- **登場キャラ**: ルカ（＋冒頭の客：炭鉱夫の老女）
- **起こる出来事**:
  1. **冒頭フック**: テレピン油と兎膠（にかわ）の匂いが充満する薄暗い工房。ルカは老女から持ち込まれた「亡き息子の肖像イコン」の修復を終える。実は息子の絵の下層には「教会への反역罪で処刑された凄惨な最期」が描かれていたが、ルカはあえてそれを剥がさず、上から穏やかな微笑みの絵具（オーバーペイント）を塗り重ねて老女に返す。
  2. 老女が涙を流して感謝し去った後、ルカは一人、懐の「5年前の偽証の羊皮紙」に触れながら、「本物なんてただの呪いだ。人を救うのはいつだって、よく出来た嘘（オーバーペイント）さ」と自嘲し、軽く咳き込む（慢性的な溶剤中毒の描写）。
- **五感・映像演出のポイント**:
  - 琥珀色のランプに照らされる顔料瓶（辰砂の赤、雌黄の黄、群青の青）のきらめき。
  - パレットナイフが絵具を撫でる繊細な金属音、外の水路を流れる白い廃液の霧。

---

## Scene 2：黒鉄の封印額縁と「生ける聖画」の出現
- **場所・時間帯**: 『atelier ペンティメント』の作業場 / Scene 1の直後
- **登場キャラ**: ルカ、キアラ、イリス（睡眠状態）
- **起こる出来事**:
  1. 工房の扉を蹴破るようにして、闇画材商のキアラ・ボーロが大型の蒸気運搬台車を押して駆け込んでくる。口には乾燥ラベンダーを咥え、真鍮と瑪瑙の左義手を鳴らしている。
  2. 台車に積まれていたのは、上層から中層への教会輸送列車から事故で落下したという**「黒鉄の特級封印額縁（棺サイズの重厚な額縁）」**。キアラは「異端審問修復庁が血眼で探している。アンタの眼で中身を鑑定しな」と大金を積む。
  3. ルカが右目に多波長光学モノクルを装着し、額縁の鉛封印をパレットナイフでこじ開ける。
  4. 中に収められていたのは絵ではなく、ボローニャ石膏のように白い肌を持ち、鎖骨に金箔の亀裂（クラクリュール）が走る美しい少女（イリス）だった。彼女の背中は、分厚く不格好な**鉛白（クレムニッツ・ホワイト）のオーバーペイント**で塗り固められ、呼吸すら封じられていた。
- **五感・映像演出のポイント**:
  - 黒鉄の額縁が開いた瞬間に立ち昇る、冷たい樟脳とフランキンセンス（乳香）、そして古いダンマル樹脂の香り。
  - モノクルの赤外線プリズム越しにルカが少女の背中を覗くと、鉛白の下から「息を呑むほど精緻な真群青（ラピスラズリ）の翼の下絵（ペンティメント）」が脈動して透けて見える視覚演出。

## Scene 3：異端審問部隊の強襲と「第一層・選択的溶剤剥離」
- **場所・時間帯**: 『atelier ペンティメント』 / Scene 2の直後
- **登場キャラ**: ルカ、イリス、キアラ、異端審問修復庁の黒衣執行官（2名）
- **起こる出来事**:
  1. 突如、工房の天窓が粉砕され、高圧蒸気噴霧器を携えた異端審問修復庁の執行官たちが突入してくる。彼らは額縁の中のイリスを見るや、「『第零聖女』の回収不能を確認――サヴォナローラ長官の命により、工房ごと焼却（サヴォナローラ処置）する！」と辰砂（バーミリオン）の火炎彩獣を展開する。
  2. キアラが義手で煙幕弾（硫化水素アンプル）を投げて時間を稼ぐが、工房は炎に包まれる。執行官の刃が眠るイリスの胸を貫こうとした瞬間、ルカはイリスの背中に走る亀裂（クラクリュール）の痛々しさに、5年前処刑台で見た師ヴェロッキオの背中を重ね合わせる。
  3. **戦闘・修復ハイライト**: ルカの口調が軽薄なものから冷徹な職人のトーンへ激変する。「――その粗悪な鉛白（オーバーペイント）、俺が引っぺがしてやる」。ルカは敵の火炎の熱量を利用しながら、テレピン油・無水エタノール・希酢酸を瞬時に調合して刷毛でイリスの背中に塗布！ 下の層を1ミリも傷つけず、膨潤した**第1層（ダンマル樹脂＋鉛白層）**の継ぎ目にパレットナイフを滑り込ませ、一気に削ぎ落とす！
- **五感・映像演出のポイント**:
  - 溶剤が鉛白層に染み込み、チリチリと白い塗膜が浮き上がるリアルな化学描写。
  - パレットナイフが白い殻を割り、その下から目が眩むような**ラピスラズリ（真群青）の輝き**が噴き出すアニメ的カタルシス。

## Scene 4：青金石の覚醒と師匠のモノグラム（クリフハンガー）
- **場所・時間帯**: 半壊した『atelier ペンティメント』 / 夜明け前
- **登場キャラ**: ルカ、イリス、キアラ
- **起こる出来事**:
  1. 第1層が剥がれ落ちた瞬間、少女のラピスラズリの瞳がカッと見開かれる。目覚めたイリスは、自分を覗き込む薄汚れたルカを見て「……まあ、なんて下品なテレピン油の臭いですこと！ わたくしの肌に気安く触れないでくださる！？」と第一声から罵倒を浴びせる。
  2. 執行官が放った辰砂の火球に対し、イリスは「無礼者」と一瞥し、**『真群青の画装展開（ウルトラマリン・ドライヴ）』**を発動。絶対防御の群青結晶障壁を展開して火球を弾き返し、光の衝撃波で執行官たちを水路の彼方へ吹き飛ばす。
  3. 戦闘後、イリスは自分が「イリス」という名前以外の記憶を失っていることに気づき愕然とする。彼女の背中にはまだ**残り6層の強固なオーバーペイント**が残っていた。
  4. **終盤の引き（クリフハンガー）**: ルカがイリスの背中の第1層が剥がれた境界線（第2層の端）をモノクルで拡大観察する。そこには、微細な左利きのハッチング（斜線描）とともに、5年前に処刑されたはずのルカの亡き師匠・**マエストロ・ヴェロッキオの固有署名（モノグラム『V』）**が刻まれていた。「……嘘だろ、師匠。なんであんたのサインが、この娘の封印にあるんだ……？」というルカの戦慄で幕を閉じる。
