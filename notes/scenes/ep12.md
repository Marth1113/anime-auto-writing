# 第12話（最終話） シーン詳細設計書 (ep12.md)

- **サブタイトル**: 第12話『大天蓋・剥離転写（グラン・ストラッポ）――嘘つきパレットが描く明日』
- **視点**: 三人称一元視点（ルカ・ヴァルツ視点）
- **目標文字数**: 5,000〜6,000文字（全12話の集大成となる最高潮のグランドフィナーレ）

## Scene 1：崩れ落ちる偽りの空と、修復師の究極の設計図
- **場所・時間帯**: 天蓋聖堂・ドーム大空間 / 午後
- **登場キャラ**: ルカ、イリス、サヴォナローラ（『偽創世の巨神』と融合）、地上から見上げるユリアンとキアラ
- **起こる出来事**:
  1. **冒頭フック**: 大聖堂の直径100メートルに及ぶ天井壁画『創世の大フレスコ』が怪物化して脈動し、鉛白の巨腕と辰砂の業火を振るって聖堂の柱を次々と粉砕する。
  2. 壁画の中心で蠢くサヴォナローラが咆哮する。「ハハハハ！ 見ろ、異端の修復師よ！ この天井の『オーバーペイント』はもはや都市の骨格そのものと癒着している！ 私を倒してこの天井を壊せば、支持体である都市の結界ごと崩落し、数十万の民が死ぬ！ 貴様らにこの空は剥がせん！」。
  3. だが、イリスの背中に立つルカは不敵に口の端を吊り上げる。「壁画と支持体が癒着してるなら、壁を壊さずに『表層の絵具（お前）』だけを一枚丸ごと引っぺがして別の布に写し取るまでだ。――お姫様、人類史上最大の**『剥離転写（ストラッポ）』**をやるぞ！」。
- **五感・映像演出のポイント**:
  - 大聖堂の天井全体が怪物として襲いかかる圧倒的なスケール感と、少しも怯まないルカとイリスのバディ感。

## Scene 2：大天蓋・剥離転写（グラン・ストラッポ）！！
- **場所・時間帯**: 大聖堂の天井ドーム全域 / 継続
- **登場キャラ**: ルカ、イリス、サヴォナローラ
- **起こる出来事**:
  1. **アニメ1クール最大のクライマックス・アクション**:
     - 第一工程【膠（グレア）の塗布と麻布張り（フェイシング）】：イリスが『原初の真群青』の翼を最大展開し、ルカが調合した「卵白と兎膠の超濃縮グレア」を光の奔流に乗せて直径100メートルの天井壁画全面へ一気に噴霧！ さらに群青の魔力糸を織り上げて、天井全体を覆う一枚の巨大な「光の麻布（カンヴァス）」としてサヴォナローラの巨神の表層へ密着させる！
     - 第二工程【乾燥収縮と剥離刃の挿入】：サヴォナローラが「小賢しい真似を！」と高熱の炎を放つが、ルカは「ありがてえ、その熱で膠が一気に乾いて収縮する！」と笑い、イリスの翼から大聖堂の頂点（天頂）へ向かって跳躍する！
     - その瞬間、イリスの放つ強烈なラピスラズリの輝きに共鳴し、モノクロームだったルカの右目に、ただ一色――**鮮烈で美しい「群青色（ウルトラマリン）」の色彩**が奇跡的に蘇る！
  2. 「視える……お前の色が、一番綺麗な青が視えるぜ、イリス！！」。ルカはドームの頂点にパレットナイフを突き立て、イリスと共に巨大な光の麻布の端を掴んで全力で地上へ向かって急降下する！
  3. **決め技発動**: **「――偽りの神話はここまでだ！ 大天蓋・剥離転写（グラン・ストラッポ）ォォォッ！！」**。
     バリバリバリッ！！ という雷鳴のような剥離音とともに、500年間都市の空を覆っていた鉛白と金箔の巨大なオーバーペイント層（サヴォナローラごと）が、一枚の巨大な布となって天井から豪快に引っぺがされる！
- **五感・映像演出のポイント**:
  - 巨大な偽りの黄金天井がベリベリと剥がれ落ち、その下から500年間隠されていた**「本物の『創世の大フレスコ』――ラピスラズリと銀箔で描かれた、息を呑むほど美しい満天の星空の下絵」**が都市全体を蒼く照らし出す、鳥肌必至のカタルシス演出。

## Scene 3：「嘘つきパレット」の最後の奇術――少女を壁から解き放つ一筆
- **場所・時間帯**: 崩れ落ちた祭壇と、星空の天井ドームの下 / 夕方
- **登場キャラ**: ルカ、イリス、ユリアン
- **起こる出来事**:
  1. 引き剥がされた偽りの壁画布の中で、力を完全に失ったサヴォナローラが「馬鹿な……これが、500年前の本物の空の色だと……？」と呟きながら気絶し、駆けつけたユリアンらによって拘束される。
  2. しかし、本物の星空壁画の中心にはまだ「イリスが切り取られた穴」が空いており、壁画のエネルギーが徐々に不安定になり始める。イリスは静かに微笑み、「ルカ、ありがとうございました。わたくしの本当の姿を見届けてくれたこと、一生忘れませんわ。さあ、都市を守るために、わたくしをあの天井の穴へ戻してくださいませ」と、再び壁画の一部に戻る覚悟を決める。
  3. **タイトル回収＆最高の逆転劇**: だがルカはイリスのデコを軽く弾き、「誰がお前を冷たい天井なんかに戻すかよ」と笑う。ルカはコートの裏から、第9話で仕込んでいた**『合成ウルトラマリンとイリスの剥がした金箔（第6層）で描いた、超精巧な身代わりの贋作核カンヴァス』**を取り出し、天井の剥落孔へと打ち込んで完璧にイン・ペインティング（補彩接合）してしまう！
  4. 天井の星空壁画はルカの「超一流の贋作核」を本物と認識して完全に安定し、都市中に温かい光を降り注ぐ。「な、なんですのそれは！？ 神聖な創世壁画を贋作で誤魔化すなんて、前代未聞の冒涜ですわ！」と驚くイリスに、ルカはニッと笑って言う。「言ったろ、お姫様。俺は人を救うためなら神様の目だって騙す、灰底街で一番の『嘘つきパレット（贋作師）』なんだぜ」。
- **五感・映像演出のポイント**:
  - 壁画の呪縛から完全に切り離され、重力に従ってルカの腕の中へと落ちてくる「ただの人間の少女」になったイリスの温もり。

## Scene 4：エピローグ――剥落の聖女と、新しいキャンバスの1ページ目
- **場所・時間帯**: 灰底街・新しく看板を掛け直した『atelier ペンティメント』 / 数週間後の晴れた朝
- **登場キャラ**: ルカ、イリス、キアラ、ユリアン（手紙または来訪）
- **起こる出来事**:
  1. 教会の旧体制（サヴォナローラ派）が崩壊し、ユリアンが新設された「真実保存修復院」の代表として上層と下層の格差是正と汚染浄化を進めていることが語られる。都市の空には、もはや鉛の霧はなく、澄み切った青空が広がっている。
  2. 再建されたルカの工房。ルカの視力は完全には戻っていないが、明暗と「イリスの群青色」だけははっきりと見えている。
  3. エプロンを着けたイリスが、「ルカ！ 今日のメレンゲ菓子こそ、わたくしが完璧な雪の白さに焼き上げてみせましたわ！ ほら、感謝して召し上がりなさい！」と胸を張って皿を差し出す（少し形はいびつだが、真っ白で甘いメレンゲ）。
  4. **大団円のラストシーン**: 二人がメレンゲを巡っていつものように軽口を叩き合っていると、工房のドアベルがチリンと鳴り、新たな依頼人が訪れる。
     ルカがパレットナイフを手に取り、「さあて相棒、今日も塗り潰された誰かの涙を、綺麗に剥がしに行こうぜ」と立ち上がり、イリスがラピスラズリの瞳を輝かせて「ええ、お任せなさいな！」と微笑む最高のカットで物語の幕を閉じる。
